# 慕德中學 2026 升中資訊日網頁

港澳信義會慕德中學 2026 升中資訊日（11 月 21 日，下午 2:00–5:00）的展區地圖及活動時間表。

- `index.html`：單一檔案網頁，直接用瀏覽器打開即可
- 3D 立體樓層地圖：點選樓層查看展區，按房號看活動內容
- 活動時間表（電腦版可收起到側邊欄）
- 意見問卷按鈕（Google Form）

## 樓層編輯器

- `editor.html`：樓層編輯器。用瀏覽器打開，拖動房間、拉角落改大小、改名稱、指定展區；可上載平面圖照片做底圖。
  改好後按「複製版面資料」，貼給 Claude 即可更新網頁地圖。修改會自動存在你的瀏覽器。
- `floorplan.json`：目前的樓層版面資料（編輯器的原始版面）。
- `floor-template.pdf`：列印用的手繪修改範本，每層一頁。
